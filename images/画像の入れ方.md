# images フォルダについて

このフォルダに各スポット・店の写真を入れます（三重旅行の画像は流用しないため空にしてあります）。

## 命名規約
- 1件につき 1〜3枚。先頭がメイン写真。
- ファイル名は `場所名のローマ字.jpg`、複数枚は `_2` `_3` を付ける。
  - 例: `meotoiwa.jpg` / `meotoiwa_2.jpg` / `meotoiwa_3.jpg`
- `app.js` の `DATA` 側では `images: ["images/meotoiwa.jpg", "images/meotoiwa_2.jpg"]` のように参照。

## 入手先
- Wikimedia Commons など、ライセンスが明記された素材を使う。
- フッター（index.html）に出典クレジットを残す。
- 画像が無い場合、カードは絵文字プレースホルダーで表示される（`renderImageBlock()` のフォールバック）。
